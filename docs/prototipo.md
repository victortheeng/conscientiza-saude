# Prototipação das Telas

O protótipo de baixa fidelidade está descrito abaixo. A implementação visual está em `index.html` e `css/style.css`.

## Tela 1 — Início
```text
┌──────────────────────────────────────────────────────────┐
│ + conscientiza.saúde     Início  Outubro  Novembro  Quiz │
├──────────────────────────────────────────────────────────┤
│ INFORMAÇÃO TAMBÉM É CUIDADO             Laços rosa/azul   │
│ Conhecimento que cuida de você.                           │
│ Texto de apresentação                                     │
│ [Explorar campanhas] [Testar meus conhecimentos]           │
├──────────────────────────────────────────────────────────┤
│ Falar sobre saúde é um ato de cuidado.                     │
│ [Card Outubro Rosa]              [Card Novembro Azul]      │
└──────────────────────────────────────────────────────────┘
```

## Tela 2 — Conteúdo educativo
```text
┌──────────────────────────────────────────────────────────┐
│ OUTUBRO ROSA                                              │
│ Cuidado e atenção com as mamas.                            │
│ Introdução              ┌ Fatores de risco ─────────────┐ │
│                         ├ Sinais e sintomas ────────────┤ │
│                         ├ Prevenção e diagnóstico ──────┤ │
│                         └ Mitos e verdades ─────────────┘ │
└──────────────────────────────────────────────────────────┘
```

## Tela 3 — Quiz
```text
┌──────────────────────────────────────────────────────────┐
│ PERGUNTA 1 DE 6                    [progresso]             │
│ OUTUBRO ROSA                                              │
│ Pergunta do quiz                                          │
│ (A) Alternativa                                           │
│ (B) Alternativa                                           │
│ (C) Alternativa                                           │
│ [Próxima pergunta]                                        │
└──────────────────────────────────────────────────────────┘
```

## Identidade visual
- Fundo em tom claro e neutro.
- Rosa para Outubro Rosa e azul para Novembro Azul.
- Tipografia Manrope em títulos e DM Sans em textos.
- Cartões com contraste, espaços amplos e navegação responsiva.
