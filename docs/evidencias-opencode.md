## Sugestões de prompts para executar
Use estes prompts como ponto de partida e adapte-os. Salve capturas reais do terminal ou do histórico do OpenCode.

1. "Analise a estrutura deste projeto e explique como HTML, CSS e JavaScript estão organizados. Não altere arquivos ainda."
2. "Revise a lógica do quiz em js/script.js. Procure erros no cálculo da pontuação, seleção de alternativas e reinício. Explique os problemas antes de corrigir."
3. "Analise a responsividade em telas de 375px, 768px e desktop. Sugira correções de CSS e explique cada alteração."
4. "Revise a acessibilidade do HTML: semântica, foco de teclado, botões, contraste e atributos ARIA. Liste problemas e implemente melhorias justificadas."
